# ATM Simulator (Python CLI Project)

This is one of my first foundational projects in Python, built to apply and master core programming concepts.

## Objective
To build a real-world application (a command-line ATM) using fundamental programming logic, data structures, and functions.

## Skills Demonstrated
* **Planning:** Designed the complete program flow using pseudocode before writing any code.
* **Functions:** Wrote modular, reusable functions for `check_balance()`, `deposit()`, and `withdraw()`.
* **Loops & Conditionals:** Used a main `while` loop to run the program and `if/elif/else` statements to handle user commands and error checking (like insufficient funds).
* **State Management:** Successfully managed the user's `balance` variable throughout the program's lifecycle.
